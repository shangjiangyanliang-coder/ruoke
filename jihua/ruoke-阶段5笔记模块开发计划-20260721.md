## 一、本阶段目标

实现「笔记模块」MVP 范围功能，得到一个能在真机上新建、编辑、保存、删除、分级、标重点、查历史、贴标签、搜索的笔记功能闭环。顺带把全项目共享的「数据库底座 + Repository 骨架」立起来，后续题库/复习等模块直接复用。

## 三、涉及数据表（B 文档，笔记块 + 标签）

1. `subject` 科目树（书-章-节容器，自引用树，含软删）
2. `note` 笔记（title + content_json + 派生 plain_text + is_draft + ai_hidden + 软删）
3. `note_version` 笔记历史版本（snapshot_json + version_no）
4. `note_highlight` 重点条（kind=red/underline + text + start/end）
5. `tag` 标签（name 唯一 + color）
6. `note_tag` 笔记-标签关联（N对N，复合主键）

## 五、分批开发与 commit 计划

### 第 1 批：地基底座（不碰 UI）
- 装 `uuid` 包；pubspec 加 `flutter_localizations: sdk: flutter`
- 建 `data/database/`：AppDatabase + 6 张表 + 各 DAO
- 建 `data/errors/`：AppException 子类 + Result
- 建 `utils/`：uuid 生成、毫秒时间戳
- `dart run build_runner build` 生成 Drift 代码
- `flutter analyze` 全绿
- commit: `feat: 立数据库底座(AppDatabase+6表+errors)`

### 第 2 批：笔记 CRUD + 富文本编辑器 + 底栏骨架
- 装 `flutter_quill`
- 建 notes feature：models + NoteRepository 接口 + LocalNoteRepository 实现
- 笔记列表页（B1） + 笔记编辑器（B1.a，flutter_quill）
- go_router 接 StatefulShellRoute 底栏（先放笔记 tab，其余 tab 占位）
- 真机验证：新建/编辑/保存/看列表
- commit: `feat: 笔记 CRUD + 富文本编辑器`

### 第 3 批：笔记分级（书-章-节树）
- note 挂到 subject 节点；浏览页按树展示
- 新建/编辑时选归属科目
- commit: `feat: 笔记分级(书-章-节树)`

### 第 4 批：划重点 + 历史版本/回退
- 工具栏红字/下划线 → 写 note_highlight
- 保存触发 note_version 快照；版本列表页 + 回退
- commit: `feat: 重点标记 + 历史版本回退`

### 第 5 批：标签管理 + 搜索
- tag/note_tag 表落地 + 标签管理页
- plain_text LIKE 搜索 + 筛选/排序
- commit: `feat: 标签管理 + 笔记搜索`

## 六、分支与提交规范

- 从 master 切 `feature/notes-mvp` 分支，本阶段 5 批 commit 都在该分支
- 每批一个 `feat:` commit，一次只做一件事
- 5 批完成且真机验证通过后，合并回 master 并 push origin

## 八、风险与注意事项

- `flutter_quill` 首次集成到主项目要调样式/工具栏，参考 `ceshi/rich_quill/` demo 代码
- `flutter_localizations` 是 SDK 自带，pubspec 走 `sdk: flutter`，不能 `flutter pub add`
- Drift 代码生成需 `dart run build_runner build`，改了表定义要重跑
- PUB_CACHE 必须在 D 盘（已持久化），新 shell 若没有 `$env:PUB_CACHE` 要同步
- 富文本栈无备胎（super_editor/appflowy 都编译失败），锁版本 `^11.5.1`
