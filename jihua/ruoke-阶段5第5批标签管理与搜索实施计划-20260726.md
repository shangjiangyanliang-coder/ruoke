# 第5批标签管理与搜索实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在稳定性批次闭环后，实现标签增改删、笔记贴/撕标签、多标签并集筛选，以及标题/正文搜索和三种排序。

**Architecture:** 复用现有 `tag`、`note_tag` 和 `note.plain_text` 表结构。新增 Tag 领域模型与 TagRepository；标签事务由 LocalTagRepository 管理，搜索由 NoteRepository 管理；页面继续通过手写 Riverpod ViewModel 接入。

**Tech Stack:** Flutter 3.44.4、Dart 3.12.2、Riverpod 3.3.2、Drift 2.34.2、go_router 17.3、flutter_test。

## Global Constraints

- 必须等待编辑器稳定性小批次自动化、用户真机测试和独立提交完成后再执行。
- 采用方案 A：标签增改删、编辑器贴/撕标签、多标签并集、标题+正文搜索、最近/最早/标题排序。
- 不实现标签拖动排序、私密标签联动、标签层级、拼音搜索、模糊纠错、全文索引、搜索历史、书章节名称搜索和分页。
- 不新增依赖，不修改表结构和 schemaVersion。
- View → ViewModel → Repository → DAO。
- 修改现有文件前备份到 `beifen/`。
- 真机测试由用户执行。
- 未经用户确认不 push。
