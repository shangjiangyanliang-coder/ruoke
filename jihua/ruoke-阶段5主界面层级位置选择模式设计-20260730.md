# 阶段5：主界面层级位置选择模式设计

## 1. 目标

修正笔记浏览、新建内容和新建笔记的范围与交互：逐级/展开浏览可在任意层级切换；创建文件夹、书、章、节时在当前范围内逐层选择创建位置；新建笔记时不再展示全局书章节列表，而是在当前笔记主界面中逐层选择归属位置。

## 2. 已确认交互

### 2.1 浏览模式切换

- 根目录、文件夹、书、章、节均显示浏览模式切换按钮。
- 逐级模式按当前层级进入下一层。
- 展开模式在同一页面展示当前节点及其后代，不跳转到独立页面。
- 展开范围严格受当前位置限制：文件夹只展开该文件夹的后代；书只展开该书；章只展开该章；节只显示该节及直属笔记。
- 切回逐级模式时仍停留在原位置。

### 2.2 新建文件夹、书、章、节

1. 用户点击顶栏“新建内容”。
2. 弹窗只负责选择内容类型并填写名称，不再用下拉列表一次展示所有父位置。
3. 用户确认名称后，弹窗关闭，笔记主页进入“选择创建位置”模式。
4. 选择模式从用户当前所在位置开始，只允许浏览当前位置及其后代。
5. 点击文件夹、书或章的整行进入下一层；合法目标的右侧显示“在此创建”。
6. 选择合法位置后才调用仓储写入数据；取消选择不产生任何数据。

各类型合法父位置：

| 创建类型 | 可选择的位置 | 其他节点行为 |
|---|---|---|
| 文件夹 | 根目录、文件夹 | 书、章、节不可作为父位置 |
| 书 | 根目录、文件夹 | 书、章、节不可作为父位置 |
| 章 | 书 | 文件夹用于继续查找书，章、节不可作为父位置 |
| 节 | 章 | 文件夹、书用于继续向下查找章，节不可作为父位置 |

### 2.3 新建笔记

1. 用户点击右下角“新建笔记”。
2. 不再弹出全局书章节列表，当前笔记主页直接进入“选择笔记位置”模式。
3. 选择模式从当前所在位置开始，范围不能越过当前节点。
4. 文件夹只能进入；书和章既能进入下一层，也能通过右侧“在此创建”选择；节没有下一层，点击节即可选择。
5. 选定书、章或节后打开新建笔记编辑器，并通过 subjectId 固定归属。
6. 取消时回到启动选择前的位置和浏览模式，不创建空笔记。

## 3. 页面状态设计

笔记主页增加可跨子路由保持的选择会话状态：

- normal：普通浏览；
- chooseContentLocation：选择文件夹、书、章或节的创建父位置；
- chooseNoteLocation：选择新笔记归属的书、章或节。

选择会话记录：启动位置、允许范围根节点、内容类型、待创建名称、当前浏览位置和启动前浏览模式。进入子层级时会话继续存在；取消或完成后统一清空。

选择模式下：

- 顶栏标题改为“选择创建位置”或“选择笔记位置”；
- 顶栏提供“取消”；
- 暂时隐藏搜索、标签、新建内容、浏览切换和笔记 FAB，避免并行启动第二个操作；
- 面包屑不能返回到选择范围之外。

## 4. 数据与组件边界

- LibraryBrowserView 继续作为唯一笔记主页和逐级浏览容器。
- 浏览模式从页面局部状态改为共享状态，使切换按钮能在根目录、文件夹、书、章、节保持一致。
- 新增 LibrarySelectionSession，统一管理内容位置选择和笔记位置选择。
- 新增层级位置选择组件，复用现有 LibraryLocation、LibraryBrowserState 和路由；不再维护全局铺平的书章节选择列表。
- LibraryContentCreateDialog 只收集类型和名称，真正创建动作延后到位置选定后执行。
- 原 showSubjectPickerDialog 不再由笔记主页 FAB 调用；文件可暂时保留，避免影响其他旧入口，待确认无引用后再决定是否删除。

## 5. 错误处理

- 名称为空时不能进入位置选择模式。
- 当前节点被删除、移动或不再属于允许范围时，停止创建并提示“目标位置已变化，请重新选择”。
- 创建失败时保留选择会话和当前位置，显示具体错误，允许用户重试或取消。
- 进入编辑器前才结束笔记位置选择会话；编辑器打开失败时回到原位置。
- 所有取消路径均不得提前写入文件夹、书、章、节或笔记数据。

## 6. 测试范围

- 根目录、文件夹、书、章、节均出现浏览切换按钮。
- 各位置切换展开模式后只显示当前节点后代。
- 新建内容弹窗不再显示全局位置下拉框。
- 四种内容类型在逐层选择中只允许合法父位置。
- 选择会话不能通过面包屑或返回操作越过启动范围。
- 新建笔记从当前位置开始选择，文件夹不可选，书、章、节可选。
- 取消内容创建与取消笔记创建均不写数据。
