# 阶段5：主界面层级位置选择模式实施计划

> **执行要求：** 使用 TDD 按任务顺序实施。每项功能必须先写失败测试并确认失败原因正确，再写最小实现。用户确认本计划前不得修改源码。

**目标：** 让逐级/展开浏览在所有层级可切换，并把新建内容、新建笔记的位置选择改为从当前位置开始的主界面逐层选择。

**架构：** 以 `LibraryBrowserView` 作为唯一浏览和位置选择容器；新增共享的 `LibraryNavigationVm` 保存浏览模式和选择会话，使状态能跨文件夹、书、章、节子路由延续。位置合法性放入纯规则模块，界面只负责展示、导航和触发合法选择；`LibraryExpandedTree` 接收当前位置，只加载该位置的子树。

**技术栈：** Flutter、flutter_riverpod、go_router、Drift、flutter_test。

## 全局约束

- 不新增第三方依赖，不修改数据库结构。
- 选择内容位置或笔记位置前不得写入数据。
- 选择范围不能越过启动选择时的当前位置。
- 文件夹不能作为笔记归属；书、章、节可以作为笔记归属。
- 修改任何现有文件前，将该文件备份到 `beifen`。
- 临时测试文件放在 `ceshi`；正式自动化测试继续放在 `test`。
- 不修改 `lujing.md`，除非用户另行明确确认。
- 不删除旧文件、备份或测试，不 push。

## 任务 2：当前位置范围与目标合法性规则

**产出接口：**

```dart
class LibrarySelectionRules {
  const LibrarySelectionRules({
    required List<SubjectFolder> folders,
    required List<Subject> subjects,
  });

  bool isWithinScope({
    required LibraryLocation origin,
    required LibraryLocation candidate,
  });

  bool canSelectCurrent({
    required LibrarySelectionSession session,
    required LibraryLocation location,
  });

  bool canEnter({
    required LibrarySelectionSession session,
    required LibraryLocation location,
  });
}
```

规则：

- 根目录会话允许整个库。
- 文件夹会话只允许该文件夹及其后代文件夹、其中的书、章、节。
- 书会话只允许该书及其章、节。
- 章会话只允许该章及其节。
- 节会话只允许该节。
- 内容类型合法父位置：文件夹/书 → 根目录或文件夹；章 → 书；节 → 章。
- 笔记合法位置：书、章、节。

- [ ] 新建 `library_selection_rules_test.dart`。
- [ ] 写文件夹范围失败测试：

```dart

  final rules = LibrarySelectionRules(
    folders: [
      folder('a'),
      folder('a-child', parentId: 'a'),
      folder('b'),
    ],
    subjects: const [],
  );
  expect(
    rules.isWithinScope(
      origin: const LibraryLocation.folder('a'),
      candidate: const LibraryLocation.folder('a-child'),
    ),
    isTrue,
  );
  expect(
    rules.isWithinScope(
      origin: const LibraryLocation.folder('a'),
      candidate: const LibraryLocation.folder('b'),
    ),
    isFalse,
  );
});
```
