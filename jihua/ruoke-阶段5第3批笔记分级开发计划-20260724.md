## 一、本批目标

把笔记列表页（B1）从当前平铺列表升级为「书→章→节→笔记」可折叠四级树（章/节可省以支持整本/整章笔记），FAB 新建按选定位置一键定级，App 首启 seed 示例科目树。完成后真机验证：树展开折叠、新建按位置挂对节点、点开读出。

## 二、功能范围（本批做/不做）

| 做的 | 不做的（留后） |
|---|---|
| 书-章-节-笔记 四级可折叠树 | 进度条/复习量（F1.21，需 review_card 数据，第4/复习阶段） |
| 节行展开折叠 | 标签视图切换（B1.c，第5批） |
| 点叶/笔记行进编辑器 | 搜索范围四类切换（第5批搜） |
| FAB 新建弹窗：当前选中/整本书/指定章-节 | 长按弹菜单 G6（编辑/删除/AI不见等，留后） |
| 笔记按真实 subjectId 归属 | 树节点增删改管理页（本批不建管理页，靠 seed） |
| App 首启 seed 示例科目 | 树拖拽排序、移动节点（V2） |

## 五、UI 结构（B1 树）

```
笔记
├ 📁 物理 [展开 ▼]            ← 学科(书 level0)，ExpansionTile
│  ├ 📖 第1章 运动学 [▼]        ← 章 level1
│  │  ├ 📄 匀速直线运动         ← 节 level2 下挂笔记
│  │  └ 📄 自由落体
│  ├ 📖 第2章 力学 [▶]
│  ├ 📝 整章笔记:力学小结        ← 笔记 subjectId 指向章(节省，line框B1支持)
│  └ 📝 整本书笔记:物理方法总览  ← 笔记 subjectId 指向书
├ 📁 英语 [▶]
└ 📝 未分类笔记(若subjectId=占位残留)
                 [+] FAB → 弹定级窗
```

## 七、真机验证清单（计划）

1. 首启 App → 笔记 tab 看到示例科目树（物理/英语）
2. 展开物理→章→节，看到第2批遗留笔记（若仍挂占位应在"未分类"）
3. FAB+→弹定级窗→选"物理/第2章 力学"→进编辑器→写→保存
4. 返回树→展开力学→看到新笔记挂在力学下（不在未分类）
5. 点开新笔记→编辑器读出→顶栏面包屑显示"物理 > 第2章 力学"
6. 退回列表删一条→从树对应位置消失

## 八、风险

- Flutter 没原生 TreeView，自写递归 ExpansionTile 要处理深层级展开状态保持（StatefulShellRoute indexedStack 切 tab 不重建，但折叠态要 ViewModel 或 PageStorage 存）
- seed 幂等：只能"表空才 seed"，不能每次启动都塞（会重复），用 count 判
- 第2批遗留笔记若 subjectId 是占位 `__default_subject__`，树上要有个"未分类"兜底分组，否则这些笔记不可见
- build_runner 改 DAO 后要重跑
