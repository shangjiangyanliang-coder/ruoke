## 线框设计约定（跨页面统一）

为后续画线框一致,定下这些全局约定:

### 顶栏(全局统一)
- 左上 `[≡]` 抽屉菜单:左滑出,承载"快速跳最近笔记/最近题/各设置子页"等快捷入口(MVP 内只挂2-3项, V2 充实)
- 中间:页标题
- 右上 `[⚙]` 设置图标:进 A3 设置页

### 底部导航(全局, 恒在)
- 5 标签:首页(A1) / 笔记(B1) / 题库(D1) / 学习(C6) / 我的(A3)
- 当前页标签高亮
- 起源页不显示底部导航:B1.a 笔记编辑器(全屏沉浸编辑)、C7 翻卡交互(全屏做题)、C19 AI讲解(意在专注)——这些"沉浸页"隐藏底部导航

### 悬浮 FAB(全局快捷)
- 在 A1 首页、B1 笔记列表、D1 题库等"浏览型页"显示 `[＋]` 悬浮按钮
- 点击弹菜单:新建笔记 / 拍照识图 / 出题
- 沉浸页(B1.a/C7/C19) 不显示,沉浸编辑/做题不打扰

### 空态统一
- 卡片型元素有数据时显示;无数据显示 `0`(不为空、便于认知)
- 列表型无数据时显示占位文案 + CTA

### 颜色/主题
- 文字主色:默认暗灰(#1F2937 类比色), 重点红(#D63333), 标签蓝绿等
- 深色模式(MVP G1): 整体背景→黑/深灰, 文字主色→浅灰;MVP 必含

### 字段命名习惯
- 时间字段:系统按本地时间读 `YYYY/MM/DD 周`
- 进度字段:`N%` 整数百分比
- 数量字段:卡片上大数字 + 单位词在前(如 "12 待复习" →大字 12, 次"待复习")

│  │ 🔍 [搜索范围 ▼] 书名/章名/节名/笔记标题名 ─┐ [搜索▶] ││  搜索范围可切四类

- **做题入口在树/列表两处**:章级[去练习]整章带 C8;单题[··]→做题也进 C8 单题刷;两条路都走 C8(只传题id或章id做参数差异),不重复造做题。
- **错题不是入口而是跳转**:错题本 C9 从 D1 顶部筛选"质量=错题"或顶部角标"错题本"进;D1 不单列错题区(错题只是题的一种状态/标签,不另设集合,避免 C9 与 D1 重复)。
- **FAB 三选项**:新建题(D2)/拍照识图出题(C1→C5 转题支线,此支线在 V2)/从笔记转题(D5),MVP D5 可用、拍照出题留 V2 占位灰显。
- **质量标 V2 先留**:MVP 题项录质量字段(D2)但筛选不显质量(留 V2);MVP 只显题型/难度/来源。
- **空态**:无题→"题库还空,录第一道题 [去录题→D2]"。
- **不可删整科目误删**:科目/章是归类容器,点删走二次确认 + 是否删其下题(防大范围误删,呼应 F3.32 重要性确认)。

### 设计说明(避坑点)
- **与B1同源另一视图**:B1 是"浏览建笔记/题"的树(含进度点),S2 是"看进度/复盘"的进度表(每章多维计数+学完比排序);数据同源(笔记/题/重点/错题/复习五维表),只是视图与目的不同,不复制数据。
- **学完比怎么算**:MVP 简法= (已做笔记数+已做题数) / (该章目标可做预期数) 的加权 sqr 近似;无严格目标时以"已建-已空"做比,留 V2 用 F3.24 设目标后真学完比;MVP算法抽象为函数,易替换。
- **五维计数全显**:每章/节恒显笔记/题/待复习/重点/错 五个计数,比 B1 顶部进度点信息更多,一眼看哪章薄弱(待复习多/错多)。
- **下钻链**:切"按节"视图后章可下钻显节;支持整章无节(F1.1.6 章可省节以做整本/整章笔记),无节项显示"整章笔记"自身一行降级计数。
- **入口多不绑标**:从 S1[章节进度细分]、B1[进度详]、A1 进度卡链;底栏不绑单一高亮。
- **空态**:无内容→"还没有任何内容,先去建笔记/录题 [去笔记→B1][去题库→D1]"。
- **不属沉浸页**:带底部导航,可被抽屉/设置打断。
