# 若可 Ruoke 学习辅助App - 产品待办需求清单（Backlog）

> 文档作用：本项目全量功能清单（Product Backlog），含 MVP / V2 / 远期池三层，统一在此登记。
> 版本：v0.2（重排版）
> 编写日期：2026/07/13
> 总体定位：用 AI 辅助做"读 → 记 → 练 → 复习"闭环的学习 App。
> 受众定位：先自己用 → 亲友用 → 未来可能上架。
> 运行形态：纯本地起步（离线可用、零服务器成本），**预留上云接口**，后期想上云可直接接入。
> 技术路线：Flutter（方案 A）。

---

## 一、阅读说明

### 1.1 编号体系
- **F1 / F2 / F3**：三大功能大块 — 笔记 / 题库 / 跨块公共能力
- 后缀数字：F1.1、F2.3 … 表示具体功能；F1.1.1 … 表示子功能/细化点
- **新功能续编**：找到对应大块续下一个号，**永不改动已有编号**

### 1.2 优先级标记
- **★★★ MVP**：第一版核心必须有
- **★★  V2**：第二版做，"有了更好"
- **★   池**：远期池，先记着不删，作为以后更新内容

### 1.3 本重排版组织思路
为方便你横扫检查，本版**按"功能大块归类"统一排列**，而不再按"轮次新增"。
每一层内部按 F1 / F2 / F3 / 系统 顺序整理，每条加"做什么"一句话注解。
想清优先级后插到对应层即可，不动已有编号。
