# 阶段5：文件夹系统浏览与统一新建实施计划

> 执行方式：每个任务遵循 Red → Green → Refactor，并在完成后运行对应定向测试。

## 目标

将笔记主页改为同页浏览模式切换，并以一个受当前位置约束的入口统一创建文件夹、书、章、节；右下角加号始终用于按既有选择器创建笔记。

## 涉及文件

| 文件 | 操作 | 作用 |
|---|---|---|
| lib/src/features/notes/view/library_browser_view.dart | 修改 | 主页顶栏、笔记 FAB、逐级/展开内容容器 |
| lib/src/features/notes/view/library_content_create_dialog.dart | 新建 | 类型选择、合法父位置选择与创建提交 |
| lib/src/features/notes/view_model/library_tree_view_model.dart | 新建或修改 | 构建包含文件夹及书章节目树的展开数据 |
| lib/src/features/notes/view/note_list_view.dart | 删除或停止引用 | 旧的独立展开页，避免重复入口 |

| test/features/notes/library_browser_view_test.dart | 修改 | 顶栏、模式切换、笔记 FAB 测试 |
| test/features/notes/library_content_create_dialog_test.dart | 新建 | 统一新建流程与位置过滤测试 |
