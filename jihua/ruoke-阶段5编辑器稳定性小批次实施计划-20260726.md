# 编辑器稳定性小批次实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复新空笔记残留和新建编辑器复用上一条内容的问题，并为首次进入转圈建立可关闭需求的自动化证据。

**Architecture:** 保持现有 View → ViewModel → Repository 分层。ViewModel 用三态保存结果区分成功、跳过空笔记和失败；View 使用当前路由初始化门禁，禁止旧 ViewModel 状态创建新 Controller，并在路由变化时释放旧 Controller。

**Tech Stack:** Flutter 3.44.4、Dart 3.12.2、Riverpod 3.3.2、flutter_quill 11.5.1、flutter_test。

## Global Constraints

- 仅处理 F1.1.10、F1.1.13、F1.1.14。
- 不修改 F1.1.11、F1.1.12、F1.1.15。
- 空笔记定义为标题 trim 后为空且 Quill 纯文本 trim 后为空。
- 空新笔记手动保存不创建并留在编辑器；保存并离开时不创建并退出。
- 标题或正文任一有内容即可保存。
- 已有笔记清空仍走 update。
- 不引入依赖，不修改数据库 schemaVersion。
- 真机测试由用户执行，开发方提供清单。
- 修改现有文件前备份到 `beifen/`。
- 未经用户确认不 push。
