# 阶段5第5批标签与搜索改进实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将第5批现有“预建标签 + 标签管理 + 持久搜索状态”改造成编辑器自由标签、标签搜索、标题/正文双匹配模式和书—章—节范围搜索。

**Architecture:** 保留现有 `tag`、`note_tag`、`note` 和 `subject` 表，不做数据库迁移。扩展领域查询模型和 Repository 接口；搜索页面使用 `autoDispose` 会话状态；编辑器已有笔记即时绑定标签，新笔记先保存正文再批量绑定待保存标签。

**Tech Stack:** Flutter 3.44.4、Dart 3.12.2、Riverpod 3.3.2（手写 Provider）、Drift 2.34.2、flutter_quill 11.5.1、go_router 17.3、flutter_test。

- [ ] **Step 4: 实现最小领域模型和查询**

`search_match_mode.dart`：

```dart
enum SearchMatchMode { contains, exact }
```

`subject_scope.dart`：

```dart
enum SubjectScopeKind { all, subtree, level }

class SubjectScope {
  final SubjectScopeKind kind;
  final String? subjectId;
  final int? level;

  const SubjectScope.all()
      : kind = SubjectScopeKind.all,
        subjectId = null,
        level = null;

  const SubjectScope.subtree(String this.subjectId)
      : kind = SubjectScopeKind.subtree,
        level = null;

  const SubjectScope.level(int this.level)
      : kind = SubjectScopeKind.level,
        subjectId = null;
}
```

扩展 `NoteSearchQuery`：

```dart
final SearchMatchMode keywordMatchMode;
final SubjectScope subjectScope;
```

默认值分别为 `SearchMatchMode.contains` 和 `SubjectScope.all()`。

`NoteDao.search()` 增加：

```dart
required NoteDaoMatchMode matchMode,
Set<String>? subjectIds,
```

- `NoteDaoMatchMode` 定义在 DAO 文件内，由 Repository 从领域 `SearchMatchMode` 映射，数据层不得反向依赖 feature 模型；
- contains 使用现有 `LIKE %keyword%`；
- exact 对标题和正文执行 SQL `TRIM` 后使用 `equals(keyword)`，确保字段首尾空白不影响完整匹配；
- `subjectIds == null` 不限范围；
- 非空集合使用 `notes.subjectId.isIn(subjectIds)`。

`LocalNoteRepository` 从未软删除科目节点解析 ID：

- `all` 返回 `null`；
- `level` 只返回 `subject.level == level`；
- `subtree` 先验证节点存在，再递归收集目标及后代；
- 节点不存在时保留 `ValidationException('所选范围已不存在，请重新选择')`，其他异常翻译为“搜索笔记失败”。
